# Grimdark CQB releases

Download installers from [Releases](https://github.com/entpnomad/grimdark-cqb-releases/releases). This repository contains release notes and update feeds; game source is private.

Mac: Alpha 0.5.1 (Intel and Apple Silicon). Windows: Alpha 0.4.0. Multiplayer requires matching builds.

The installers are not yet signed with a paid identity or notarized. See each release for installation instructions.

`latest-mac.json` and `latest-windows.json` identify the newest published installer per platform, including Alpha releases. Update a feed only after its installer upload succeeds.
